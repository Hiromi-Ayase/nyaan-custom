## Warshall–Floyd 法

`warshall_floyd(d)` は正方距離行列を破壊的に更新し、全点対最短距離を求める。`d[i][j]` には直接辺の最小重み、辺がなければ十分大きい値を入れる。

実装は最初に対角成分を 0 に上書きするため、負の自己ループを初期行列に入れても保持されない。また、無限大を表す値の加算を特別扱いしない。負辺がある場合の `INF + 負値` やオーバーフローに注意し、厳密な到達不能判定が必要なら別途管理する。

通常の入力で処理後に `d[i][i] < 0` があれば負閉路が存在する。その影響を受ける距離は有限の最短距離ではない。

時間は $O(V^3)$、行列以外の追加領域は $O(1)$。空行列はそのまま返る。
