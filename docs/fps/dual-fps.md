## 周波数領域に保持する多項式

`DualFPS<fps>(f)` は多項式を NTT 済みの形で保持し、繰り返す加算・乗算で変換回数を減らす。`get()` で係数列へ戻す。

多項式同士とスカラーの加減乗算、単項マイナス、`<< s` による $x^s$ 倍を提供する。多項式同士の演算は非 const 参照を受け取り、両オペランドの変換容量を変更することがある。シフト量は非負とする。

公開メンバ `deg` は数学的な次数そのものではなく保持する係数長。`f` は通常の係数列ではなく変換値で、場合により最高次係数を `top` に分離する。`get()` の結果には余分な高次の零が含まれることがあるため、必要なら `shrink()` する。

対応する NTT 向け FPS 型と十分な根の次数が必要。ヘッダに AVX2 指定を含む。容量が同じなら演算は変換長に比例し、容量拡張や係数への復元には $O(N\log N)$ の変換を行う。
