## 固定底の累乗表

`FastPow<T, LOG = 21>(base, I = 1)` は同じ底の累乗を多数求めるための表。`I` は乗法の単位元。

`operator()(e)` は `base^e` を返す。指数は非負の `long long` で、`e < 2^(3*LOG)` の範囲を指定する。上位ビットは表の参照に使われないため、この範囲を超えると正しい累乗にならない。シフトが型の幅を超えないよう、`1 <= LOG <= 21` を目安に設定する。

指数を `LOG` bit ずつ 3 桁に分け、最大 3 要素を掛ける。前計算の時間・領域は $O(2^{LOG})$、問い合わせは $O(1)$ 回の `T` の積。既定値では各表が約 200 万要素あり、必要な指数の範囲に合わせて `LOG` を小さくできる。
