## C++11 向けの数論変換

`NTT<mint>` の C++11 向け実装。原始根を **`3` に固定**しているので、`3` が原始根である NTT 向け素数の法を使う。

`ntt(a)`、正規化済みの `intt(a)`、通常の畳み込み `multiply(a,b)`、変換済み配列を倍長へ拡張する `ntt_doubling(a)` を提供する。畳み込みの入力は両方とも非空とする。

変換長は法 $p$ の `p-1` を割り切る 2 冪で、内部表のため `v2(p-1) >= 3` の法を使う。係数型も必要な演算とコンパイル時の `get_mod()` を提供する必要がある。共通テンプレートや係数型自体が C++11 に対応するかは別途確認する。

時間 $O(N\log N)$、領域 $O(N)$。`multiply` 後により大きな長さの直接変換を行う場合は内部表を再設定する。通常版や SIMD 版と同名の型を定義するため併用しない。
