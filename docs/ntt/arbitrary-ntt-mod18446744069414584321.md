## 法 2^64 − 2^32 + 1 の NTT

`ModInt18446744069414584321` と `NTT18446744069414584321` による固定素数 $p=2^{64}-2^{32}+1$ の演算。グローバルな `ntt18446744069414584321` も利用できる。

- `ntt(a)` / `intt(a)` は modint 配列の変換と正規化した逆変換。
- `multiply(a,b)` は modint 版と整数配列版。整数版は非負の係数を渡し、答えの各成分が **法未満**である場合に整数畳み込みとして使える。
- `bigint_mul_base_10_9(a,b)` は下位桁から並べた基数 $10^9$ の非負整数を乗算する。各桁は `[0,10^9)`。

両入力は非空とする。法には $2^{32}$ の根まで存在するが、実装では長さを `int` とシフトで扱うため、その表現範囲とメモリ容量が別の制限になる。多倍長整数版も、基数変換後の畳み込み係数が法を超えない範囲で使う。

時間 $O(N\log N)$、領域 $O(N)$。128 bit 整数演算を利用する。
