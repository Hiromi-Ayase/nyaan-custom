## ソース埋め込み用の整数列符号化

`Base64::encode(vector<T>&)` は各要素を固定ビット幅で詰めて文字列にし、`Base64::decode(string)` は `vector<long long>` に復元する。先頭文字にビット幅を保存する独自形式で、標準 Base64 との互換性はない。

空列・全要素 0 の列は `a[0]` や `clz(0)` による未定義動作がある。負数は元の型の幅を使うが、復号時の符号拡張は行わない。既存コードへ数列を埋め込む際も、対象の値域で往復確認して使う。

時間は要素数 n と幅 B に対し $O(nB)$、符号長は $O(nB/6)$。
