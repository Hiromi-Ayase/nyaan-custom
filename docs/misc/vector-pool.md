## 添字によるオブジェクトプール

`VectorPool<T,ptr_t=int>(s=4)` は vector の添字をハンドルとして使う。0 は nil 用に予約し、`s > 0` とする。

`my_new(args...)` は構築した要素の添字、`alloc()` は初期化しない添字を返す。`pool[i]` で参照し、`free(i)` で再利用可能にする。`free` は要素のデストラクタを呼ばない。`clear()` は全ハンドルを無効化して管理情報だけを戻す。

容量拡張で参照・ポインタが無効になるので添字を保持する。確保は償却 $O(1)$、解放は $O(1)$、領域は最大容量に比例する。
