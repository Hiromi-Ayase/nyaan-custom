## 前計算による定数時間の逆元

素数 `MOD` を固定し、`Inverse_O1<MOD>` の構築時に逆元表と有理近似の表を作る。

`inv(a)` または `operator()(a)` で `1 <= a < MOD` の逆元を返す。問い合わせは $O(1)$。`0` や合成数の法は対象外。

$n=\lceil MOD^{1/3}\rceil$ とすると、表の大きさはおおむね `MOD / 1024 + n*n + 1024*n`。構築時間・領域はこの表サイズに比例し、大きな法ではオブジェクトをスタックに置かないようにする。配列長の計算にコンパイル時の浮動小数点演算を用いるため、使用するコンパイラで定数式として扱える必要がある。
